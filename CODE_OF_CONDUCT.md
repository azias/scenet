# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its code of conduct. Please read
it — the canonical text is authoritative and is not reproduced here.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good faith, and accept that maintainers may decline contributions
for reasons of scope or direction without that being a judgement of you.

## Reporting

Report unacceptable behaviour privately using GitHub's own reporting feature, or by opening a
private security advisory on this repository (Security tab, "Report a vulnerability") if you would
rather the report not be public. Reports are handled confidentially.

Maintainers may remove comments, commits, issues and pull requests that violate this code, and may
block accounts for sustained or severe violations.
